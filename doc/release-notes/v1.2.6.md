# Resin v1.2.6

## 订阅导出增强 (Native sing-box Outbounds for ShadowTLS Plugin)

- **原生 sing-box 展开导出**：将带有 ShadowTLS 插件的 Shadowsocks 节点自动展开为原生的两个 sing-box 出站条目（内层 SS 与外层 ShadowTLS 隧道，并通过 `detour` 关联），无需依赖客户端对 Resin 自定义 SIP003 插件的支持。
- **解决 Karing 客户端 `plugin not found: shadow-tls`**：客户端使用 `/sub/<token>/singbox` 订阅格式可直接载入原生出站，规避 Karing 无法执行第三方外部插件及历史版本 Clash 转换器丢弃内层协议的问题。
- **Mihomo 兼容性验证**：Clash Meta 导出在官方 Mihomo v1.19.32 下完成 SS2022 + ShadowTLS v2/v3 双层凭证回显测试。
- **标签与引用保护**：自动分配唯一出站标签，保留所有原始别名；不支持自定义 CA 与证书钉扎时遵循既定错误/跳过策略。
