# Resin v1.2.5

## 订阅导出增强 (ShadowTLS Feed Pairing)

- **原生 SS 与 ShadowTLS 自动配对导出**：识别来源订阅中 `detour` 指向 `type: shadowtls` 的 `type: shadowsocks` 原生节点，并自动完成链式依赖分析与合并导出。
- **Clash Meta / Mihomo 聚合输出**：将配对节点合并为带有完整 `plugin: shadow-tls` 及 `plugin-opts` 的 `type: ss` 节点，解决 Karing 等客户端将底层 ShadowTLS 隧道单列为独立节点导致的测速 EOF 与连接异常。
- **URI 与 v2ray-base64 支持**：将配对节点合成为标准 SIP003 `plugin` 格式的 Shadowsocks URI。
- **sing-box 原生引用重写**：sing-box 格式保留原生出站节点，并在重命名时同步重写 `tag` 与 `detour` 引用。
- **安全隔离与错误保护**：仅在同一来源订阅内部解析配对依赖，防止跨订阅凭证混淆；检测并安全跳过循环依赖、孤立传输节点及歧义引用。
