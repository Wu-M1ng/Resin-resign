# Resin v1.2.7

## 节点探测熔断休眠与防刷流优化 (Circuit Breaker Dormant Probing Policy)

- **探测失败计数封顶（Max Probe Failures）**：节点连续探测失败计数在达到 `max_probe_failures`（默认 5 次）时原子封顶，彻底消除坏节点失败计数值无上限累积的问题。
- **后台周期探测休眠**：健康检查循环（`scanLatency` 与 `scanEgress`）及到期检查（`isLatencyProbeDue`）自动跳过失败计数达到上限的休眠节点，彻底阻断无效节点在后台死循环发起网络探测，大幅节约机场订阅流量。
- **订阅刷新自动唤醒**：订阅更新（`SubscriptionScheduler`）拉取成功并同步应用后，原子唤醒该订阅下的所有休眠节点并将失败计数重置为 0，赋予其全新的探测预算。
- **即时测速穿透保障**：管理员通过 WebUI 节点列表闪电测速按钮或 API 发起的主动即时探测完全不受休眠策略限制，保证故障排查与人工诊断的即时响应。
- **系统配置与 WebUI 动态支持**：控制平面接入 `max_probe_failures` 运行时配置项（中文：`最大探测失败次数（停测休眠）`），支持参数校验、一键还原默认值及双语国际化。
